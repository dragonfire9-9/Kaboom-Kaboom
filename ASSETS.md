# SoulBound — Asset Guide

Everything the game ships with is either generated by code or free/open-licensed.
Swap any file for a better one **with the same name** and no code changes are needed.

## Font

| File | Font | License | Source |
|---|---|---|---|
| `assets/fonts/PirataOne-Regular.ttf` | **Pirata One** (gothic blackletter, very legible) | SIL OFL 1.1 (`assets/fonts/OFL.txt`) | https://fonts.google.com/specimen/Pirata+One |

Free alternatives with the same mood (all OFL, on Google Fonts): **UnifrakturMaguntia** (heavier
blackletter), **Metamorphous** (runic/medieval), **Cinzel Decorative** (carved-stone capitals).
Change `FONT_PATH` in `src/assets.rs` to switch.

## Music — `assets/audio/music/`

| File | Used for | Notes |
|---|---|---|
| `menu_theme.wav` | Main menu | 24 s seamless D-minor drone pad |
| `battle_theme.wav` | In a run | 32 s seamless loop with a 90 BPM heartbeat pulse |

`.ogg` is also supported (smaller files): keep the same base name, change the extension in
`src/assets.rs`.

## Free sources for better sounds

- **freesound.org** — huge library; filter by *Creative Commons 0* to avoid attribution work.
- **OpenGameArt.org** — game-ready packs, e.g. search "RPG sound pack", "magic SFX", "dark ambient".
- **Kenney.nl** — public-domain (CC0) packs: *Interface Sounds*, *Impact Sounds*, *Sci-fi Sounds*.
- **jsfxr** (https://sfxr.me) — generate retro SFX in the browser: use *Laser/Shoot* for
  `soul_bolt`, *Hit/Hurt* for `hit` and `player_hurt`, *Explosion* for `soul_burst` and
  `enemy_death`, *Powerup* for `soul_absorb`, *Blip/Select* for the UI sounds. Export WAV.
- **Music**: incompetech.com (Kevin MacLeod, CC-BY, e.g. *"Dark Times"*, *"Long Note"*),
  OpenGameArt "dark ambient loop".

## Sprites (procedural — no image files needed)

Glows and particles are generated at startup in `src/vfx/textures.rs` (white images, tinted
with the palette in `src/palette.rs`, HDR tints feed bloom). Characters will be built from
shapes, procedural textures and shaders in later stages.

If you want hand-drawn art instead, make these sprite sheets (PNG, transparent background,
one row per animation, frames left to right, pixel-art friendly sizes):

| Sheet | Frame size | Animations (frames) |
|---|---|---|
| `player.png` | 48×48 | idle (6), move (8), dash (4), cast (5), hurt (3), death (10) |
| `wraith.png` | 48×48 | float (6), attack (6), hurt (2), death (8) |
| `hexcaster.png` | 48×64 | idle (6), cast (8), hurt (2), death (8) |
| `husk_brute.png` | 96×96 | idle (4), walk (8), charge windup (6), charge (4), recover (6), death (10) |
| `shardling.png` | 24×24 | skitter (4), attack (4), death (5) |
| `chained_warden.png` | 192×192 | idle (6), sweep (10), slam (10), enrage (8), death (16) |
| `hollow_queen.png` | 160×192 | idle (8), cast (10), summon (8), teleport out/in (6 each), death (16) |
| `projectiles.png` | 32×32 | soul bolt (4), charged shot (6), hex orb (6) |

Keep the palette: deep purples for bodies, teal (`#4DF2DB`) for soul-light, ember (`#FF8029`)
for anything dangerous.
