# Kaboom: Jujutsu Kaisen (NeoForge 1.21.1)

A Jujutsu Kaisen mod for Minecraft **1.21.1** on **NeoForge 21.1**, using **GeckoLib 4.7** for animated
creatures and outfits. Mod id: `jjk`.

## Build and run

Requirements: JDK 21. The Gradle wrapper downloads everything else (NeoForge, Minecraft, GeckoLib, JEI).

```bash
cd jjk-mod
./gradlew runData        # generates chest loot tables + structure biome tags into src/generated (CI does this too)
./gradlew runClient      # start the game with the mod
./gradlew build          # jar in build/libs/jjk-<version>.jar
./gradlew runGameTestServer   # boots a headless server and runs the mod's GameTests
```

To install in a normal game, put `build/libs/jjk-*.jar` and the matching GeckoLib jar
(`geckolib-neoforge-1.21.1-4.7.x.jar`) into your `mods/` folder. JEI is optional.

### Continuous integration

`.github/workflows/jjk-mod.yml` runs on every push that touches `jjk-mod/`:

1. `runData`, then commits any changed `src/generated/resources` back to the branch
2. `build` (compile + jar)
3. `runGameTestServer`: 19 GameTests (rolls, data sync, items, Infinity, domains, curses, shikigami,
   missions, bosses...)
4. **Client screenshots:** launches the real client under a virtual display, creates a flat world, runs
   through the features and pushes screenshots to the `jjk-ci-screenshots` branch (see
   `ClientShowcase.java`; only active when `JJK_SHOWCASE=1`)

## Playing

New players get one Cursed Energy Scroll and one Clan Scroll. Right-click them to roll.

| Key | Action |
| --- | --- |
| **R** | Activate the selected ability |
| **Z** / **Shift+Z** | Cycle abilities forward / back |
| **V** | Domain Expansion (Grade 1+) |
| **G** | Reverse Cursed Technique (once learned from Gojo or Yaga) |

Exorcise curses (they spawn at night, in the dark, in villages and in "negative emotion" structures) to
gain experience, rise from Grade 4 to Special Grade, raise max CE and unlock abilities. Talk to sorcerer
NPCs for missions, trades (register a Student ID first) and training.

### Commands

`/jjk info [player]`. Operators also get: `/jjk grade <grade>`, `/jjk xp <n>`, `/jjk technique <id>`,
`/jjk tier <tier>`, `/jjk clan <clan>`, `/jjk restriction <none|physical|cursed_energy>`, `/jjk fill`,
`/jjk unlock rct|black_flash`, `/jjk reset`.

### Config (`config/jjk-common.toml`)

Rarity weights for the technique pool, clan bias strength, Heavenly Restriction chances, base CE and regen,
CE cost and cooldown multipliers, XP rates, the curse spawn rate, griefing toggles (Hollow Purple block
erasure, domain barrier blocks, other destructive techniques) and domain slow motion.

## Project layout

```
src/main/java/com/kaboom/jjk/
  JJKMod.java            mod entry point, registers every DeferredRegister
  config/                JJKConfig (ModConfigSpec)
  data/                  CursedEnergyData (player attachment), enums: Technique, Clan, CETier, CENature,
                         Grade, HeavenlyRestriction, Rarity; ModAttachments, ModTags, CurseSight
  roll/                  RollEngine (weighted, clan-biased), RollService (server-authoritative flow)
  ability/               Ability registry, effects library, AbilityHandler (keys), BlackFlash,
                         DomainManager/DomainType (domes, sure-hit, clashes), JJKDamage
  item/                  scrolls, fingers, cursed tools, Prison Realm, cursed objects, GeckoLib armor
  entity/                TechniqueProjectile, CurseEntity + CurseType, ShikigamiEntity + ShikigamiType
  boss/                  BossEntity (phases, boss bar, music) + BossBrains (per-boss attacks)
  npc/                   SorcererNpc (dialogue, trading), CurseUserEntity, missions, trades
  block/                 domain barrier/floor blocks
  effect/                Exiled, Sealed, Nullified, Infinity, Simple Domain, Domain Amplification
  worldgen/              CurseSpawner, NpcSpawner
  event/                 player data, combat, items, armor bonuses, Sukuna takeover, commands, advancements
  network/               payloads (sync, rolls, keys, FX, domains, NPC dialogue)
  particle/              tintable particle types + client particle
  sound/                 ModSounds (one sound per ability, domain, curse and boss track)
  client/                HUD, roll screen, NPC dialogue, cinematics (shake/flash/titles/fog), renderers
  datagen/               chest loot + biome tag providers
  compat/jei/            optional JEI info pages
  gametest/              GameTests run in CI
tools/                   Python generators for textures, sounds, GeckoLib models, lang, JSON, structures
```

Every placeholder asset is generated by a script in `tools/` (run from `jjk-mod/`):

| Script | Output |
| --- | --- |
| `gen_textures.py` | item icons, GUI parchment, technique icons, particles, block textures |
| `gen_geo.py` | GeckoLib geo/animation/texture for curses, shikigami, bosses and outfits |
| `gen_skins.py` | NPC player skins |
| `gen_sounds.sh`, `gen_ability_sounds.py` | placeholder `.ogg` sounds and boss music |
| `gen_lang.py` | `en_us.json` |
| `gen_resources.py` | sounds.json, item/block models, recipes, tags, loot tables, advancements, spawns |
| `gen_structures.py` | structure `.nbt` templates + jigsaw/structure-set JSON |
